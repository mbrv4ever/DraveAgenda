## ⬇️ Downloaden (Windows, geen Python nodig)

### [👉 Download DraveAgenda 1.1.1](https://github.com/mbrv4ever/DraveAgenda/releases/latest)

1. Klik op de link en download het **.zip**-bestand.
2. Pak het uit: rechtsklik → **Alles uitpakken...**
3. Dubbelklik op **DraveAgenda.exe**.

> Zie je een blauw scherm "Windows heeft uw pc beschermd"? Klik op **Meer informatie** → **Toch uitvoeren**.

## 📱 Ook op je Android-telefoon

In dezelfde [release](https://github.com/mbrv4ever/DraveAgenda/releases/latest) staat ook een **.apk** voor je telefoon, met een eigen snelgids. De telefoon werkt samen met de pc-app: op de pc kies je **Telefoon koppelen** en typ je de code op de telefoon over. Alles blijft op je eigen pc en telefoon (geen cloud). Onderweg ook bijwerken? Dat kan met het gratis **Tailscale** op pc en telefoon.

Installeren: open de link op je telefoon, download het .apk-bestand en tik erop. Vraagt Android of je "onbekende apps" wilt toestaan? Tik op **Instellingen** en zet het aan.

## Vanaf de broncode

Installeer Python 3.10 – 3.13 en de benodigde pakketten (zie `requirements.txt` als die er is), en start het hoofdbestand (`.py`). Eventuele `.bat`-bestanden doen dit voor je.
